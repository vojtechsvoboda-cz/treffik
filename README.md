# Treffik – návrh redesignu

Statický web s analýzou současné aplikace, user flow, proklikávacím prototypem a nápady.

- `public/index.html` – celý návrh v jednom souboru
- `public/s/` – screenshoty současné aplikace (analýza)
- `wrangler.jsonc` – nasazení na Cloudflare Workers (statické assety ze složky `public`)
